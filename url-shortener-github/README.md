# Сервис сокращения URL

Учебный проект на **Node.js + Express + NeDB**.
NeDB — документная NoSQL-база. Данные хранятся в файле
`data/links.db` и сохраняются после перезапуска.
Устанавливать отдельный сервер базы данных не требуется.

## Запуск

Нужен Node.js версии 22.9 или новее.
В папке проекта выполнить:

```sh
npm ci
npm start
```

Сервис доступен по адресу http://localhost:3000.
Папка и файл базы создаются автоматически.

Для изменения настроек скопировать `.env.example` в `.env`.
При изменении PORT нужно также изменить порт в BASE_URL.

## Маршруты

Все запросы — GET. Параметр url должен содержать исходный адрес.

| Маршрут | Поведение |
|---|---|
| /create?url=ithub.ru | Создаёт короткую ссылку: created: true. Если адрес уже есть — та же ссылка и created: null |
| /refresh?url=ithub.ru | Заменяет основную ссылку: refresh: true. Если адреса нет — refresh: null |
| /alias?url=ithub.ru | Добавляет ссылку: alias: true. Если адреса нет — выполняет /create с created: true |
| /remove?url=ithub.ru | Удаляет все ссылки адреса: deleted: true. Если адреса нет — deleted: null |
| /короткий_код | Перенаправляет на исходный адрес с HTTP 302 |

Ответ при создании:

```json
{"original":"ithub.ru","short":"http://localhost:3000/a1b2c3d4e5f6","created":true}
```

При ошибке возвращаются original и соответствующий флаг операции со значением
false. Неверный URL даёт HTTP 400, ошибка базы — HTTP 500.
Неизвестная короткая ссылка даёт HTTP 404.

Обновление /refresh отменяет старую основную ссылку, сохраняя алиасы.
Удаление /remove удаляет основную ссылку и все алиасы.

## Валидность URL

Адрес ithub.ru принимается, 12345 — нет.
Поддерживаются HTTP, HTTPS, домены с зоной и полные IP-адреса.
Для адресов без протокола при переходе добавляется https://.
Доступность сайта не проверяется.

Исходный адрес сравнивается после удаления пробелов по краям:
ithub.ru и https://ithub.ru считаются разными записями.

Адреса с параметрами & и # нужно кодировать в query-параметре.
Пример:

```text
http://localhost:3000/create?url=https%3A%2F%2Fexample.com%2Fpage%3Fa%3D1%26b%3D2
```

## Файлы

- src/server.js — запуск сервиса.
- src/app.js — маршруты и ответы.
- src/store.js — работа с NoSQL-базой и короткими кодами.
- src/validate-url.js — проверка URL.

Для учебного запуска используется один процесс Node.js на один файл базы.
